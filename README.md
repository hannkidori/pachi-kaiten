# パチ回転計

パチンコの回転率をホールで打ちながら計測し、実戦の記録を自動で残す Flutter アプリ
(Android / iOS)。完全無料・広告なし・**通信ゼロ**・オフライン完結。ダークテーマのみ、
数字は等幅。

## 設計思想 —「消す選択肢に入らないアプリ」

2 つの原理で作る:

1. **消す理由を作らない** — 広告なし・通信ゼロ・軽量・ユーザーに入力を強いない。
2. **消せない理由を作る** — 実戦から操作ゼロで溜まるデータ(育つ機種マスタ + 足跡ログ)
   だけを残す。迷ったら常に操作が少ない方・画面が少ない方を選ぶ。

したがって「操作が増える機能」(機種マスタ配信・収支集計・店舗プロファイル・インポート等)
は削除し、「勝手に溜まるもの」だけを残している。

> 全機能版(機種マスタ配信・収支集計・店舗プロファイル・インポート付きバックアップ)は
> **`v0-full` タグ**に保存されている。

## 主な機能

- **計測**: カスタムテンキーで決定タップごとにカウンタを記録。差分から回転率を算出。
  現金・持ち玉の両区間を計測に算入(250玉=1000円 / 1円貸しは 1000玉=1000円)。
  大当り復帰で基準を付け替え。ボーダー比(上=緑/下=赤)と期待値をリアルタイム表示。
- **育つ機種マスタ**: 機種は「名前 + ボーダー」で登録。ボーダーは **4円用 / 1円用の
  2 スロット**(自動換算せず、どちらもユーザー入力値が正)。計測開始時、貸玉設定に応じた
  スロットを使い、未入力なら**その場で入力を求めて保存**する。
- **自動足跡ログ**: セッション終了・台移動・復帰カード終了で、ユーザー入力なしに 1 行の
  足跡を自動保存(日付・機種名・回転率・総回転・期待値・投資・大当り回数)。終了時の
  回収額は任意(スキップ可)で、入力すれば P/L も残る。count 0 件は残さず破棄。
- **足跡(履歴)**: 時系列リスト 1 枚(新しい順)。集計・グラフ・編集はなし。行タップで削除のみ。
- **エクスポート**: 登録機種 + 足跡ログを JSON 1 ファイルで共有(機種変更時の持ち出し用)。
  インポートは持たない。

## 構成

- `lib/logic/` — 純粋な計算ロジック(回転率・期待値・rebase・持ち玉換算・異常値判定)。
  `flutter test` でユニットテスト済み。
- `lib/models/` `lib/db/` `lib/repositories/` — sqflite の永続化層(machines / sessions /
  entries / traces / settings)。スキーマは v1。
- `lib/state/` `lib/ui/` — 計測画面・スタート・足跡・設定などの UI。

## リリース署名(Android)

`android/key.properties` がある場合だけ本番鍵で署名する(このファイルと鍵は
git 管理外)。**無い場合はデバッグ鍵のままで、Google Play にはアップロードできない。**

1. 鍵を作る(パスワードは自分で決めて安全に保管する):

   ```sh
   keytool -genkey -v -keystore ~/pachi-kaiten-upload.jks \
     -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```

2. `android/key.properties` を作る:

   ```properties
   storeFile=/絶対パス/pachi-kaiten-upload.jks
   storePassword=（手順1で決めたもの）
   keyAlias=upload
   keyPassword=（手順1で決めたもの）
   ```

3. `flutter build appbundle --release` で署名済みの AAB ができる。

> 鍵を失うと同じアプリとして更新できなくなる。バックアップ必須。

## DB マイグレーション

スキーマを変えるときは `lib/db/database.dart` の `_dbVersion` を上げ、**必ず**
`_migrations` に手順(`ALTER TABLE` など)を追記する。追記を忘れると起動時に
例外になり、気付かずにデータを消すことはない。

`_baselineVersion`(現在 6)未満からの更新だけは、リリース前の互換の無い
スキーマなので作り直す。公開後は常に引き継ぐこと(育てた機種マスタと足跡は
このアプリの資産そのもの)。
