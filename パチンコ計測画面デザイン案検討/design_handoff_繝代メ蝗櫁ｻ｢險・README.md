# Handoff: パチ回転計（パチンコ回転率計測アプリ）全画面デザイン

## Overview
パチンコの回転率（1000円分あたりの回転数）をホールで打ちながら計測する計器アプリの全画面UIデザイン。ターゲット実装は **Flutter（Android + iOS）**。完全無料・広告なし・通信ゼロ・アカウントなし・権限要求なし。

設計原理（全実装判断はこの2つに従う）:
1. **消す理由を作らない** — 広告なし・軽量・入力を強いない・邪魔をしない
2. **消せない理由を作る** — 実戦から操作ゼロで溜まるデータ（育つ機種マスタ＋足跡ログ）だけが残る

## About the Design Files
このバンドルの `計測画面プロトタイプ v2.dc.html` は **HTMLで作られたデザインリファレンス（インタラクティブプロトタイプ）** であり、そのまま出荷するコードではない。タスクは、このデザインを **Flutter で再現実装する** こと（Flutter環境が未整備なら標準的な Flutter プロジェクト構成を新規作成する）。HTMLファイルをブラウザで開くと5画面（ホーム／スタート／計測／足跡／設定）が横並びで表示され、フル操作可能（開始→決定→大当り→台移動→終了→足跡保存の一筆書きが動く）。挙動に迷ったらプロトタイプを触って確認すること。

## Fidelity
**High-fidelity（hifi）**。色・タイポグラフィ・余白・状態遷移・文言はすべて確定値。ピクセル基準は幅390pt（iPhone標準）で設計。文言は一字一句このまま使う（情緒的文言の追加禁止）。

## 世界観・禁止事項
- 計測器・タコメーターの道具感。ギャンブル系の金ピカ・ネオン表現は全面禁止
- ダークテーマのみ（テーマ切替なし）。純黒に近い背景、OLED省電力も実利
- 数字が主役。等幅フォント（tabular figures）、IBM Plex Mono系
- 音は使わない。フィードバックは **視覚＋ハプティクスのみ**
- 左手親指のみで操作する前提。高頻度操作は画面下部1/3に配置
- 禁止: 広告スペース、課金導線、シェア、評価依頼、情緒的文言（「お疲れさまでした」等）、集計・グラフ・分析画面の追加

## 計測の概念（最重要仕様）
- **現金/持ち玉の区別は存在しない**。「決定」=「1単位（1000円分＝現金でも玉でも）消化した」の意味のみ
- **回転率 = 総計測回転 ÷ 消化単位数（千円換算）**
- 「投資」という言葉は使わない。**「消化」**（例: `消化 12k分`）。円マークは極力出さない
- ボーダーはユーザー入力値をそのまま使う（換算・補正一切なし）。機種ごとに **4円用/1円用の2スロット**
- **クイック計測**: 機種もボーダーも選ばず計測だけ可能。この場合ボーダー由来の表示（B表記・判定色・破線・ボーダー比バナー・EV）を全て非表示。回転率・グラフ・全操作は通常通り

## State Management
- **セッション**: `machineIdx | null(クイック)`, `sessionBorder`(開始時に固定), `lastCounter`, `segments[{spins, yen}]`, `unit(1000|500)`, `hit`, `moveArmed`, `undoSnapshot`(1段のみ), `commitCount`
- **派生値**: `rate = Σspins × 1000 ÷ Σyen`、`diff = rate − border`、`EV ≈ yen × (rate−border) ÷ border`（10円単位丸め）
- **決定コミット**: `delta = 入力値 − lastCounter`。`delta ≤ 0` または `delta > 40 × unit/1000` で異常値シート。正常時 segments に `{spins: delta, yen: unit}` を追加し lastCounter 更新
- **大当り確定**: lastCounter を再入力値に rebase のみ（segments 追加なし）、undo 無効化
- **永続化**（端末内のみ、通信ゼロ）: 機種マスタ（名前＋4円B＋1円B）、足跡ログ `{date, machine|null, rate, spins, yen, payout|null, ev|null, bd|null}`、設定（unit/lend/sleep）、オンボーディング済みフラグ、進行中セッション（クラッシュ・再起動復帰用 → ホームの復帰カード）
- 足跡削除は物理削除（復元なし）。機種削除は足跡に影響しない

## Assets
外部アセットなし。フォントのみ: IBM Plex Mono / IBM Plex Sans JP（Google Fonts。Flutterでは `google_fonts` パッケージまたは同梱）。アイコンは ★ ⇄ ↺ ✎ ‹ › ✕ 等のグリフで代用しているため、Flutter では線の細いミニマルなアイコン（Material Symbols thin 等）に置換可。**タコメーター/等幅数字モチーフのアプリアイコン**（ダーク地＋氷青シアン、金・玉・7・ドル袋の直喩回避）は別途要制作。
