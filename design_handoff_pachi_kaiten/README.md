# Handoff: パチ回転計 — ホーム / 計測 / 機種選択・登録 リデザイン

## Overview
パチンコの回転数（千円あたりの回転率）を計測するAndroidアプリ「パチ回転計」の主要3画面のUIブラッシュアップ。
狙いは次の3点。
1. **開いてすぐ計測に入れる**（履歴・記録はサブのサブ扱い）
2. **長時間表示しても電池を食わない**（純黒背景、発光面は線と文字だけ）
3. **左手・片手操作**（テンキーの ⌫／決定 列を左側に）

既存アプリのスクリーンショット（`reference/`）が改善前の状態。`design.dc.html` が改善後のデザイン。

## About the Design Files
`design.dc.html` は **HTMLで作った設計リファレンス**（見た目と挙動を示すモック）であり、そのまま流用する製品コードではない。
タスクは、このデザインを **対象コードベースの既存環境（Flutter / Kotlin+Compose / React Native など、既にあるもの）で再現する** こと。既存のコンポーネント・命名・状態管理の流儀に合わせて実装する。環境が未定の場合は、Android向けに最も適切なフレームワークを選んで実装する。

ファイルの開き方: ブラウザで `design.dc.html` を開く。キャンバス上に全画面が 390×844 のアートボードとして並ぶ。上から「機種選択・登録」「計測」「ホーム」の順。各アートボードには `data-screen-label` 属性が付いている。

## Fidelity
**High-fidelity**。色・文字サイズ・余白・角丸はすべて最終値。ピクセル単位で再現すること。
ただし、アートボードの外枠（`border-radius:36px; border:1px solid #2c2e33`）と、上部の「12:33 / 60%」行は端末のステータスバーを模したダミーなので実装しない。

## 共通ルール
- 背景は **純黒 `#000000`**（OLED省電力）。面を光らせない。ボタンは「暗い塗り（#0d0e11）」か「1〜1.5pxの枠線」のみ。
- アクセントは **ミント `#38c99a`** 一色。主要CTAは `background:#0b2a21; border:1.5px solid #38c99a`（暗い塗り＋ミント枠）。
- 大当りだけ **アンバー `#f0b64a`**（枠 `#6a4a0e`）。ボーダー未達は **赤 `#d9736a`**（枠 `#6a342f`）。
- 数字はすべて `font-variant-numeric: tabular-nums`（等幅数字）。
- フォントは Noto Sans JP（400/500/700）。Androidの Noto Sans CJK JP で代替可。
- 画面の左右パディング: ホーム 24px、計測・機種選択 20px。上パディング14px（ステータスバー下）、下パディング 18〜24px。
- タップ領域は最小 44px。
- 余白の吸収は `flex:1` のスペーサーで行い、固定高さの要素（テンキー等）は下に寄せる。

## State Management
```
Session {
  id, machineId?: string, startedAt, lastInputAt,
  unitYen: 500|1000|2000,        // 1回の投入金額
  startCount: number,            // 打ち始めの数字
  entries: [{ count: number, yen: number, at }],  // 決定ごとの台の表示値
  jackpots: [{ at, entryIndex }],
}
Machine { id, name, border4: number, border1?: number, lastUsedAt }
Settings { unitYen default, rateMode: 4|1 }
```
派生値: 総回転 = 最新count − startCount、計測金額 = Σyen、回転率 = 総回転 / (計測金額/1000)。千円ごと回転 = 隣接entry差分を yen/1000 で正規化。
- ホームは `activeSession` の有無で通常／計測中を切替。
- 「戻す」はスタック（entriesのpop、jackpotsも整合）。
- セッションは端末ローカルに即時永続化（アプリ終了で消えない）。
